## （2）创作方案

### 作品主题

**《灵感收纳盒：绝对本地的多模态精神档案库》**

### 作品基础信息

B 轨（实用工具轨），网页应用（Web App）

### 选题原因

作为高敏感度的文科生，日常会产生大量多模态素材（文本、截图、配乐），它们散落于各大社媒与备忘录中，极难回溯。同时，未成型的私密灵感存在隐私焦虑，不愿上传云端。且杂乱的堆积会严重污染灵感空间。

### 梳理痛点

1. 多端数据割裂，历史碎片难以精准检索；
2. 现有云端工具缺乏"数据主权"，且界面缺乏审美呼吸感；
3. 缺乏对信息的"分层管理"，高价值灵感与备用素材混杂。

### 提出设想

设计一款无后端、纯前端的单文件 Web App。采用浏览器本地存储（IndexedDB），数据绝不上传服务器。创新性地提出"三层空间"架构：存放备用素材的「冷库」、存放高敏灵感的「工作台」，以及沉淀核心思想的「内核」。通过标签与父子级双向关联构建知识网。界面采用复古未来主义流线感，提供日/夜双模式。

**技术路线说明**：单文件 HTML（原生 HTML+CSS+JS，不引入 React/Vue 框架），用户双击文件即可在手机、电脑上离线运行；数据存储使用浏览器 IndexedDB（文本 + Base64 图片）；导出备份使用原生 JS 将数据导出为 JSON 与 Markdown 格式。纯前端无服务器，黑客"无从下口"，唯一风险 XSS 通过 textContent 转义防范。

### 预计产出（本次实践聚焦核心 MVP）

一个可跨端（手机/电脑）离线运行的 .html 文件。具备多模态录入、全局实时搜索、抽屉式沉浸阅读体验，以及保障数据绝对安全的"一键 JSON 导入/导出"功能。

## （3）AI 工具使用说明

### 1. 使用环节与工具

- **需求推演与产品设计**：主要使用 DeepSeek Chat 与 TRAE 通过多轮深度对话，推翻 AI 的惯性方案，确立了产品的核心痛点与"三层空间"架构。
- **代码生成（Vibe Coding）**：全程使用 TRAE（电脑本地模式）。通过自然语言编写底层约束提示词，让 AI 输出纯 HTML+CSS+JS 代码。
- **调试与验证**：使用 TRAE 的预览功能与浏览器控制台排查报错。

### 2. 关键步骤截图与说明

> （提交时在此处插入你在 Trae / DeepSeek 里对话的截图，并配以下图注）

- **截图 1：推翻 AI 的平庸套路**

  - 图注：我提出想直接上传 MP3/MP4，AI 指出纯前端存储大文件会导致浏览器内存溢出（OOM）。我接受"轻量文件本地存储、重型多媒体外链引用"的分层方案，并将其写入产品反思。

### 3. 判断、取舍与反思

- **拒绝 AI 惯性**：大模型极易生成"大而全却平庸"的模板。创作者的价值在于提供"真实痛感"（如隐私焦虑、信息污染），并用人类的审美去约束 AI 的输出。
- **技术的降维打击**：为了追求纯前端离线运行的安全感，我放弃了炫技的拖拽与多媒体上传。这种"为了绝对的数据主权而妥协部分花哨功能"的取舍，是本次 Vibe Coding 最重要的成长。
- **边界认知**：AI 是极好的代码打字员和逻辑查错员，但"我要做什么"、"为什么这么做"的终极问题，必须由我作为产品经理来回答。

> 以下是作品实际做到 v1.3.5 后的新素材。实践一是否加入、加多少，由你按老师口味决定；正文里"数据绝不上传服务器/绝对本地"等措辞若保留，建议在反思部分补一段"理念进化"说明，避免与实践二的云同步功能自相矛盾。

### 可直接粘贴的一段"理念进化"反思

> 作品完成 V1.0 后，我开始在电脑、iPad、手机三台设备上真实使用，很快撞上"绝对本地"的代价：数据被物理隔离在每台设备里，手机上记下的灵感电脑看不见。我没有简单地"上个云"，而是把隐私模型从**物理隔离**升级为**密码学隔离**：引入 GitHub Gist 作为只存密文的"哑存储"，用同步密码经 PBKDF2（15 万次迭代）派生 AES-256-GCM 密钥，所有加密解密只在本机发生——服务器、平台甚至代码作者都只能看到乱码。本地优先的底线没有变：断网时全部功能照常可用，关闭同步、删光云端，应用毫发无损。这次取舍让我真正理解了"零知识（zero-knowledge）"架构：安全不靠相信某家公司，而靠数学。

### 可写进"判断、取舍与反思"的新一条

- **方案要向真实使用低头，但底线要用技术守住**：三端割裂的痛感是在真机日常使用中才暴露的，规划阶段无法想象；而面对"上云"诱惑，我没有放弃数据主权，而是花更多成本去理解加密、合并冲突、墓碑删除这些机制。产品经理的工作不是一次定调，而是在真实反馈与初心之间持续做有依据的折中。
