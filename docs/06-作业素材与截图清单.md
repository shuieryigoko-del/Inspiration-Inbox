### 演示录屏脚本（V1.4.3 版，60-120 秒）

1. 双击/桌面图标打开 App（展示全屏独立应用、断网可开）；
2. 录入一段灵感文字 + 两个标签 + 一张图片（正文里顺手粘一个 https 网址）→ 点"封存碎片"；
3. 瀑布流出卡片 → 网址显示为紫色可点击链接（V1.4）→ 搜索框实时过滤 → 点标签/切 Tab；
4. 点卡片 → 抽屉滑出，背景仍可滚动（手机上展示半屏 44vh → 点抓条展全屏 92vh → 收回）；切换日夜模式；
5. 点导出备份 →（电脑）展示备份文件夹自动覆盖 latest.json；
6. **云同步段（亮点）**：手机上录一条新碎片 → 切到电脑/iPad 画面，切回前台 1～2 秒内容自动出现；
7. **离线段（亮点）**：飞行模式下照常封存 → 联网后自动补传；
8. 删除测试数据后导入 JSON，数据完整恢复；结尾给三空间 Tab + 顶栏全景。

录屏工具：Win 用 `Win+G`（Xbox Game Bar）；iPad/手机用自带屏幕录制。三端同步段落可用两台设备同框或后期拼图。

## 四、调试与验证报告素材（实践二常被要求）

每次遇到问题，在 `docs/素材/开发日志.md`（需要时我帮你建）记三行：
**现象（贴报错截图）→ 怎么向 AI 描述 → 怎么解决的**。

本轮（10-30）已有的真实调试案例，直接可写进报告：

| 现象 | 根因 | 解决版本 |
|---|---|---|
| iOS 输入框聚焦自动放大 | iOS 对 <16px 输入框的默认行为 | v1.1 |
| 三端收不到更新（SW 缓存 HTML） | Service Worker 旧策略 cache-first | v1.2 改网络优先 + 更新 toast |
| 手机点安装无反应/Edge 报已添加但无图标 | 已有快捷方式冲突/容器无快捷方式权限 | v1.3.1–1.3.3 引导式安装 |
| iPad 右列卡片白块只剩 × | iOS Safari CSS 多列布局渲染缺陷 | v1.3.4 flex 分列重写 |
| 电脑自动同步比手机慢 | 无"回前台"触发 + GitHub API 60 秒缓存 | v1.3.5 回前台触发 + 45 秒轮询 + no-store |
| 封存频弹保存框 / 图片卡飞到别列又闪回 / 抽屉盖住右列 / `#A#B#C` 连成一个标签 | 自动备份兜底下载 + load 后跨列重排 + 抽屉浮层不占位 + 标签只按空格拆 | v1.4.1 四项同修：未授权不弹下载、aspect-ratio 占位不重排、抽屉背景让位、# 也作分隔符 |
| 同步文件近 1MB 后同步变得很慢（像失效） | 每轮轮询都全量下载+原样上传近 1MB 密文 | v1.4.2 ETag 304 条件拉取 + 状态指纹跳过空转上传，单测 8 项 |
| 手机抽屉固定 62vh，背后碎片流可见太少 | 底部抽屉只有一档高度 | v1.4.3 半屏 44vh/全屏 92vh 两档，抓条与按钮切换，打开默认半屏 |
| 加密自测 | —— | cloudSync.selftest() 三项全 true 可写进报告 |
