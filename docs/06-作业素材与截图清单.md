### 演示录屏脚本（30-90 秒，建议今天跑通后立刻录）

1. 打开 index.html（展示双击即开 / 断网可用）；
2. 录入一段灵感文字 + 两个标签 + 一张图片 → 点"封存碎片"；
3. 瀑布流出现卡片 → 搜索框输入关键词实时过滤 → 点标签/切 Tab；
4. 点卡片 → 抽屉滑出，背景仍可滚动；
5. 切换日夜模式；
6. 点导出 JSON → 展示下载文件；（Chrome）展示备份文件夹自动覆盖 latest.json；
7. 删除数据后导入 JSON，数据完整恢复；
8. 结尾给一个三层 Tab 或顶栏的全景。

录屏工具：Win 用 `Win+G`（Xbox Game Bar）；iPad/手机用自带屏幕录制。
