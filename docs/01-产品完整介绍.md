## 一、产品定位与核心理念

| 项目 | 内容 |
|---|---|
| 产品名称 | 灵感收纳盒（Inspiration Inbox） |
| 产品定位 | 高敏人群与创作者的"绝对本地、多模态、防丢失"精神档案库 |
| 核心理念 | 数据主权绝对归用户所有（无需登录、纯前端本地存储）；通过空间分层解决"信息污染"；通过网状关联建立个人审美图谱 |
| 视觉风格 | 复古未来主义、极简流线、建筑感、毛玻璃质感（日/夜双模式） |
| 作品轨道 | AI 课程 B 轨（实用工具轨），网页应用（Web App） |

### 1.1 要解决的真实痛点

1. **多端数据割裂**：灵感散落在微信、备忘录、AI 对话、浏览器收藏夹等不同平台，历史碎片难以精准检索；
2. **多模态素材无法关联**：文字、图片、链接、声音之间无法建立联系；
3. **隐私焦虑**：现有云端工具大多需要账号，私密灵感不愿上传；界面缺乏审美呼吸感；
4. **信息污染**：缺乏对信息的分层管理，高价值灵感与备用素材混杂，杂乱堆积污染灵感空间。

### 1.2 产品哲学

- **从"信息滞积"到"知识代谢"**：让积压的碎片被拿出来"晒太阳"，成为可调用的工具与素材，而非黏着的负担；同时刻意保留"不代谢"的冷库空间。
- **数据主权即安全感**：纯前端单文件、无服务器、数据不离开浏览器——物理级隔离，黑客"无从下口"。在 AI 时代，把数据留在本地，是抵抗算法剥削和隐私泄露的防御性设计。
- **为人（而非平台）而设计**：不追求大而全的模板，只为真实的"痛感"服务。

## 二、核心架构：三层空间（Spatial Layering）

为解决"灵感"与"素材"混杂导致的污染问题，设立三个完全隔离的 Tab：

### 2.1 冷库（Cold Storage）

- **定位**：存放低情感、高实用素材（剪辑 BGM、配色卡、散落文献截图等）。
- **风格**：弱化呼吸感，强调极致的工具性。像仓库的货架，可用稍暗的色调。
- **逻辑**：不需要写长篇大论的想法，只打客观标签（如 #赛博朋克、#BGM/高燃），方便未来检索。
- **比喻**：博物馆的库房，不常打开但保证安全；压缩存储、索引化、可导出。

### 2.2 工作台（Workspace / Workbench）

- **定位**：默认主界面。存放高情感、碎片化的灵感。
- **风格**：极致的建筑美学沉浸感——建筑感、极简、大留白、日夜模式。
- **逻辑**：支持复杂的嵌套、关联、情绪化标签；瀑布流展示、标签过滤、全文检索、随机抽取（灵感碰撞）。
- **比喻**：设计师的桌面，随手可及。

### 2.3 内核（Core Vault）

- **定位**：高度凝练的结构化档案（个人成长报告、小说世界观等）。
- **风格**：极度克制。不能是散落的瀑布流，必须是结构化的文档（Markdown 渲染的目录树或折叠面板），像一本庄严的、不可轻易修改的"羊皮卷"。
- **逻辑**：禁止随意修改；支持一键导出 Markdown；承担数据管理、导入导出、设置的工具箱职能。

## 三、功能全景（含已实现与未实现的所有设想）

### 3.1 多模态录入机制

- **基础字段**：长文本录入、多维标签（如 #科幻 #待用）。
- **图像**：支持上传/粘贴图片，前端用 Canvas 压缩后转 Base64 存入本地。
- **音乐/重型多媒体（降维妥协）**：**不允许直接上传 MP3/MP4**（会导致浏览器内存崩溃 OOM）。改为"链接引用"模式：
  - 支持粘贴音频直链、封面图；
  - 音乐导入弹窗（极具建筑感的极简输入框）包含：音频链接、封面图、"当时感受（听歌通感，如'像极地干冰的摩擦声'）"、随想备注；
  - 具备"一键粘贴剪贴板"功能；
  - 渲染极简 HTML5 audio 播放条。

### 3.2 展示与交互（抽屉式与防遮挡）

- **瀑布流主视图**：基于 CSS Columns 的多端自适应卡片流（电脑 3 列 / 平板 2 列 / 手机 1-2 列），保持建筑感留白。
- **卡片悬浮反馈**：Hover 时轻微上浮并加深阴影。
- **抽屉式详情（Drawer）**：放弃画中画居中弹窗（会遮挡背景）：
  - 手机端：点击卡片从底部向上滑出抽屉（占屏 60%）；
  - 电脑端：从右侧滑出抽屉（宽 40%）；
  - 抽屉打开时**不加全黑遮罩**，背景瀑布流依然可以上下滑动，实现"一边看详情，一边翻找其他灵感"；
  - 滑出动画平滑（transition: transform 0.3s ease-out）。
- **多选勾选关联**：**绝对禁止拖拽交互**（移动端触摸冲突严重）。在抽屉内点击 [+ 关联素材]，背景卡片出现勾选框，确认后建立关联。
- **抽屉内推入导航**：点击"包含素材"列表中的子素材，抽屉内容平滑推入子素材详情，左上角出现 < 返回按钮。

### 3.3 网状关联与防丢安全网（借鉴 Obsidian）

- **双向绑定**：A 关联 B 后，B 在主视图隐藏（折叠进 A 的详情页）；但底层数据中 B 依然独立，仅增加 parentId = A。
- **数据平等原则（绝对死规定）**：所有录入的素材（无论是否被关联），在 IndexedDB 底层必须拥有平等的独立数据记录，**绝对不能"关联即删除/隐藏原记录"**——关联只是在原记录上增加一个 parentId 属性。
- **全局检索穿透**：搜索关键词时必须能搜到被折叠的 B；B 的卡片上标注 🔗 关联自：[父级内容前10个字]，点击可跳回父级。
- **剥离与恢复**：子素材 B 可一键剥离（parentId = null），重回独立卡片；独立卡片也可随时被"吸入"主卡片。
- **上帝视角**：顶部设"显示全部素材"开关，一键平铺所有隐藏的子素材，防止遗忘。

### 3.4 检索与分类体系

- **统一单页应用（SPA）**，一镜到底，不做多风格分类界面（避免视觉疲劳和技术混乱）。
- **极简顶部**：搜索框 + 最高级别大分类 Tab（三层空间）。
- **动态过滤**：输入关键词或点击标签时，界面不跳转，不符合条件的卡片淡出消失，符合条件的流畅重排。
- **标签系统（Tag）**：不用严格"文件夹分类"，用多维度标签（一张卡片可有 #科幻 #色彩 #灵感 多个标签）；点击任意标签，瀑布流只显示该标签卡片。

### 3.5 数据安全与防清空

- **存储**：大容量 IndexedDB。
- **防丢**：顶部常驻 [一键导出 JSON]（全量数据备份）与 [一键导入]；内核空间支持 [一键导出 Markdown]（提取所有 space='core' 数据，按标题+正文合并生成 .md 文件下载）。
- **备份策略（三重保险）**：
  1. 本地 .html 文件 = 作品本身，存 E:\Projects\；
  2. 云端对话记录（Trae/DeepSeek）保存代码与讨论；
  3. GitHub 仓库 + GitHub Pages 免费托管，获得永久网址。

### 3.6 换肤系统（多主题）

保留所有功能，仅切换 CSS 变量即可换肤（Token 消耗极低）：

1. **极简流线 / 毛玻璃苹果风**（默认）：日间银白（#F5F5F7 底 / #FFFFFF 卡 / #1D1D1F 字），夜间太空曜石（#0F0F11 底 / #1C1C1E 卡 / #F2F2F7 字）；毛玻璃 backdrop-filter: blur；微圆角 12-16px。
2. **古籍线装风**：微微泛黄的宣纸白（#f4f1ea），宋体，行距极大，无多余边框、只有细细线条，像在古书留白处写批注。
3. **赛博废土/暗黑风**：呼应科幻、SCP。极深黑灰底，冷色调文字，标签带微弱荧光感，像私人机密数据库。
4. **包豪斯/新客观主义**：极强黑白对比，粗线条，大色块，绝对理性的排版，像先锋现代主义杂志。

### 3.7 未来愿景（V3.0 拓展包）

- **音乐专属卡**：封面、直链播放、通感评论的完整卡片形态。
- **AI 辅助挂件**：调用大模型 API——根据图片自动提取艺术风格标签（如"赛博朋克/巨物恐惧"）；根据文字推荐色彩与配乐。
- **PWA 支持**：可添加到桌面主屏幕，像原生 App 一样全屏运行。
- **与 Obsidian 衔接**：导出的 Markdown 可直接拖进 Obsidian；本产品是收集碎片的"前哨站"，Obsidian 是"总图书馆"。
- **风格探索备选**：新粗野主义（Neo-Brutalism）/ 瑞士国际主义网格 / Bento 便当盒布局——极简建筑感的几种参考流派。

## 四、技术底座（绝对死规定）

1. **技术栈**：单文件 HTML（内联 CSS + 原生 Vanilla JS）。**绝对禁止** React、Vue 或任何外部依赖库。代码必须双击即可在断网状态下运行。
2. **存储**：浏览器原生 IndexedDB 持久化，**绝对不使用 localStorage**（要存图片）。数据不传服务器，保证绝对隐私。
3. **安全**：渲染任何用户输入的文本时，必须使用 textContent 或做 HTML 转义，**严禁直接使用 innerHTML**，防止 XSS 注入。
4. **视觉铁律**：禁止直角和粗黑线；卡片、输入框、按钮用微圆角（12px-16px）；柔和阴影 + 毛玻璃；CSS 变量控制日/夜双模式。
5. **响应式**：完美适配电脑、iPad 和手机屏幕。
