📲 安装到主屏幕

iPhone / iPad 上只有系统自带的 Safari 浏览器能把网页装成全屏独立 App，Edge、Chrome 的菜单里都没有这个选项（苹果的系统限制）。

  1. 如果你现在在 Edge 里：先复制地址栏里的网址。
  2. 打开 Safari（蓝底、白色指南针图标），粘贴网址打开本应用。
  3. 点地址栏旁边的「分享」图标（一个方框、中间有向上箭头；iPad 在右上角，iPhone 在底部）。
  4. 在分享菜单里往下滑，点「添加到主屏幕」；如果出现「以网页 App 方式打开」开关，请把它打开。
  5. 点右上角「添加」，主屏幕就会出现紫底白「灵」字的图标。

⚠️ 主屏幕 App 第一次打开时里面可能是空的——iOS 规定它与 Safari 标签页（以及 Edge）各自是独立的数据容器，数据并没有丢。回到有数据的页面点「☁ 云同步」配好令牌和同步密码，再在主屏幕 App 里点「☁ 云同步」输入同一组令牌密码，数据就全部过来了；不想用云同步，也可以在旧页面「导出备份」、在主屏幕 App 里「导入」。

安装弹窗没有自动出现时，可以用浏览器菜单手动添加：

  1. 华为浏览器（鸿蒙）：点网页右下角的 ∷ →「添加至桌面」。这样生成的是书签快捷方式，打开时地址栏和底部工具栏仍然在——鸿蒙没有 PWA 独立窗口机制，官方已确认这一点，不是操作问题。
  2. 想让它全屏（鸿蒙）：同一个 ∷ 菜单里点「全屏浏览」，地址栏和底部工具栏会一起收起，而且不会随上下滑动弹回来；退出时左右滑一下（系统返回）即可。
  3. 想少点两次：华为浏览器「我的 → 设置 → 浏览设置」里打开「滑动隐藏底部工具栏」，之后向下滑动网页时上下两条栏会自动收起。
  4. vivo / 小米 / 其他浏览器：菜单「⋮」或「∷」→「添加到桌面」；若菜单里有「安装应用 / 安装到主屏幕」，优先点它（部分机型能装成不带地址栏的独立窗口）。
  5. 出境易里的 Edge / Chrome：容器里的应用拿不到「创建桌面快捷方式」权限，所以菜单里找不到「添加到桌面」是正常的；要用它们，只能在出境易内部打开网页。

请直接在浏览器里打开本网页再操作，不要从桌面旧图标点进来；装好新图标后，旧的书签式图标（顶部带地址栏的那个）可以删掉。

提示"已添加/已下载"但桌面上找不到图标，按顺序排查：

  1. 左右滑动桌面的每一屏、翻开所有文件夹——新图标有时被放到最后一屏。
  2. 关闭「锁定桌面布局」：长按桌面空白处 →「桌面设置」（或 系统设置 → 桌面和壁纸 → 桌面设置），关掉「锁定布局」后，回到网页重新添加一次。
  3. 出境易用户：打开「出境易」App 本体，图标很可能被放进了它内部的桌面；在里面长按本应用图标，选「添加到主屏幕」。同时到 系统设置 → 应用和服务 → 应用管理 → 出境易 → 权限，允许「创建桌面快捷方式」。
  4. 以上都不行就用华为浏览器打开网址 → 菜单 →「添加至桌面」兜底，图标一定能出现（这种方式打开时顶部带地址栏，功能完全一样）。
